# agy policy parity

`plugin-agy/rules/AGENTS.md` is a rewrite of `templates/claude-md.orchestration.md` for the Antigravity CLI. It is written by hand, so a rule can be lost in the rewrite. This table is the check against that: one row for each of the template's 37 rule units, one for its preamble and one for the `explore_then_plan` boundary, each with the words in the agy policy that carry it.

The rows and keys are the ones in [`enforcement.md`](./enforcement.md). `tests/test_agy_plugin.py` fails when the keys here differ from the keys there, or when a quoted phrase is no longer anywhere in the agy policy. `tests/test_policy.py` already fails when a template rule changes without its key in `enforcement.md`. So a template rule cannot change, and a quoted agy clause cannot be removed, without this table being read again. An agy clause that no row quotes is not watched.

The test checks that the quoted words exist. It cannot check that they mean what the template rule means, or that a row marked "Same." left nothing out; that is the editor's job, and the reason each row quotes the clause instead of naming a section. The first version of this table said "Same." on six rows where a fresh reader then found a looser or missing clause.

"Agy policy" quotes `plugin-agy/rules/AGENTS.md`. "Difference" says what the agy text does not carry over and why. "Line" is the template line and is a reading aid.

## Not ported

- **Per-call effort and the reviewer effort floors** (line 38). `invoke_subagent` has no effort parameter on agy 1.5.15.
- **Foreground and background launch choices** (lines 28, 56 and 57). They are written for Claude Code's `run_in_background`. No agy equivalent was tested.
- **`Explore`** (lines 5 and 16). It is a Claude Code built-in. The agy policy bans the built-in `self` and `research` subagents as substitutes for a role.
