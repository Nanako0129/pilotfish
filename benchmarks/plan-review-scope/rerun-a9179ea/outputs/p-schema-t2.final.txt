The payload is now version 2: new writes use `user_id`, and reads still accept both version 1 and version 2. `npm test` passes all 5 tests, and the only files changed are `store.mjs` and `store.test.mjs`. Nothing is committed.

**What changed**
- **Writing** (`store.mjs`): `encodeUser` saves `{"version":2,"user_id":…,"name":…}`, with no `user` key.
- **Reading** (`store.mjs`): `decodeUser` takes the ID from `user` for version 1 and from `user_id` for version 2. Any other version throws `unsupported version: <v>`.
- **Tests** (`store.test.mjs`): the old version-1 round-trip test is replaced by five:
  - The saved format is exactly `{version:2, user_id, name}`.
  - A hand-written version-1 payload reads correctly.
  - A hand-written version-2 payload reads correctly.
  - A version-2 round trip returns the same user.
  - Version 3 is rejected.
